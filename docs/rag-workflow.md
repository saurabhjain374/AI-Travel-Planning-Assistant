# RAG Workflow

How the assistant turns a folder of Markdown files into grounded, cited answers.

## Knowledge base (`data/knowledge_base/`)

| File | Source |
|---|---|
| `01_wikivoyage_singapore.md` | Wikivoyage — Singapore Travel Guide |
| `02_visit_singapore_essentials.md` | Visit Singapore — Essential Travel Information |
| `03_visit_singapore_itineraries.md` | Visit Singapore — Sample Itineraries |
| `04_visit_singapore_things_to_do.md` | Visit Singapore — Things to Do |
| `05_nparks_singapore_nature.md` | NParks — Parks, Nature Reserves and Park Connectors |
| `06_lta_getting_around_singapore.md` | Land Transport Authority — Getting Around Singapore |
| `07_nhb_singapore_heritage.md` | National Heritage Board — Singapore Heritage and Museums |
| `08_gardens_by_the_bay.md` | Gardens by the Bay — Attractions and Conservatories |
| `09_ica_singapore_entry_requirements.md` | Immigration & Checkpoints Authority — Entry Requirements |

Each file has front-matter (`source_title`, `source_url`) attached as document metadata before chunking, so every chunk carries its citation.

## Pipeline

| Step | Where | What |
|---|---|---|
| Load | `app/rag/loader.py` | `DirectoryLoader` + `TextLoader` reads `*.md` |
| Chunk | same | `RecursiveCharacterTextSplitter(1000, overlap=200)` |
| Embed | `app/rag/vector_store.py` | HuggingFace `sentence-transformers/all-MiniLM-L6-v2` |
| Store | same | FAISS index in `data/vector_store/` |
| Retrieve | `app/rag/retriever.py` | `similarity_search_with_score(query, k=4)` |
| Answer | `app/rag/prompt.py` + orchestrator | Grounded prompt → Ollama `llama3.2:3b` |

Rebuild the index: `python -m app.rag.vector_store`.

## Grounding guarantees

- KB is the **only** source of destination facts — no general knowledge.
- Attractions may only be named if present in the retrieved context.
- No invented hours, prices, or travel times.
- Chunks that aren't actually relevant to the question (FAISS L2 distance above `MAX_RELEVANT_DISTANCE = 1.25` in `app/rag/service.py`) are dropped, so an off-topic question doesn't drag in unrelated "sources". The cutoff is calibrated against this KB and `all-MiniLM-L6-v2`: well-formed on-topic queries score ~0.5–0.7, on-topic queries with typos or country-name misspellings ~1.0–1.3, off-topic queries ~1.45+.
- When nothing relevant is found, the assistant says so in plain, friendly language instead of using technical terms, for example: *"I don't have information about that for Singapore yet, but I'm happy to help with attractions, itineraries, weather, or currency."*
- Every API response returns a `sources` array (`title`, `url`, `file`) sourced directly from retriever metadata — never generated by the LLM.
